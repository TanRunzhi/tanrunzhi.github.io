# 页面风格：以浅色为主

本项目所有静态页面（HTML）的视觉风格应当遵守以下约定：

1. **背景以浅色为主**：页面背景使用浅色系（如浅灰蓝 `#f5f7fb`、浅灰白等），避免大面积的深色 / 暗色背景。
2. **主色点缀而非铺满**：品牌色（蓝 / 青等）仅用于强调、链接、激活态等点缀，不要作为整块背景或按钮主填充色。
3. **按钮与卡片**：默认使用白底浅描边的浅色样式；即便是「主按钮 / 激活标签」也应采用浅色渐变（如浅蓝→淡青 `#e8f1ff → #e0f7ff`）+ 深蓝文字（`#1d4ed8`），而不是深蓝实底白字。
4. **一致性**：新增页面（如 `demo/`、`crypto/` 等子目录页面）必须保持与首页 `index.html` 一致的浅色视觉语言。
5. **可读性**：文字使用深灰 / 深蓝等深色，保证在浅色背景上有足够对比度。

> 例外：仅在用户明确要求深色模式时，才允许使用深色调。
