# 本地数据抽屉：主内容左移避让（全局约定）

当页面加载了 `assets/localdb-panel.js`（右侧「本地数据」抽屉）时，**抽屉打开后主内容必须左移避让**，否则会遮挡页面功能（尤其拖动改宽度时）。该效果已做成全局样式，无需各页面重复实现。

约定：

1. **左移逻辑由抽屉组件单点注入，页面不要各自写**：`localdb-panel.js` 已注入全局 CSS：
   `body.ldb-open .wrap{ margin-right: var(--ldb-w, 30vw); transition: margin-right .25s ease; }`
   脚本在抽屉打开时给 `body` 加 `.ldb-open` 类，并把当前抽屉宽度写入 CSS 变量 `--ldb-w`；拖动改宽度时该变量实时更新，主内容随之联动。
2. **主内容容器统一为 `<main class="wrap">`**：所有页面（首页、各子模块页）都必须把主内容包在 `<main class="wrap">` 中（与浅色风格规则一致），全局左移规则才能自动生效。新增页面也必须遵守，不要另起容器类名，否则不会左移。
3. **不要在具体页面里重复实现该效果**：不要再在页面 `<style>` 中写 `body.ldb-open .wrap` 之类规则，避免与全局规则冲突或遗漏。
4. **抽屉是「常用字符串」的唯一入口**：模块页不要在自身再放一份「常用字符串 / 片段」输入框（如加解密页曾有的 snippet 框），统一用抽屉的「➕ 添加」与搜索来管理，避免功能重复。
5. **抽屉开关按钮要放在卡片内右上角，不要飘在页面右上角**：默认开关按钮是页面级固定定位（页面右上角）。若希望它落在卡片（`<main class="wrap">`）内右上角，只需在 `<main class="wrap">` 内第一个子元素放一个锚点 `<div id="ldb-toggle-anchor"></div>` 即可——定位样式由 `localdb-panel.js` 全局注入，页面无需再写 CSS。未放锚点的页面会回退为页面右上角常驻按钮。
   - 注意：UUID / demo 等页顶部若已有「🗃️ 本地数据」链接（跳转 `data/localdb.html` 管理页），那是独立导航，与抽屉开关按钮不同，可保留。

影响范围：index / crypto / uuid / demo 均加载该抽屉，已自动获得左移效果；`data/localdb.html` 为抽屉数据的管理页本身，不加载抽屉组件。
